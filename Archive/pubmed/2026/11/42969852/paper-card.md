## 02 一句话总结

本文提出 AxialTAD——一个仅含 113K–137K 参数的紧凑深度学习模型，通过 Axial Contrast Module（ACM）显式编码 Hi-C 局部 patch 中沿行/列方向的接触强度对比（TAD 边界的几何特征），在人类 4 个细胞系（GM12878、HeLa-S3、IMR-90、K562）的 TAD 边界预测中达到与 571K 参数的 CNN+Transformer 基线（deepTAD）相当的 F1（差异 ≤ 0.02），并在两个小鼠数据集上优于参数匹配的 CNN 对照，表明在该任务上大架构并非必要。

## 03 研究问题

- **具体问题**：TAD 边界预测是否需要大容量深度学习架构？能否通过显式编码 TAD 边界的几何先验（沿行/列方向的接触强度突变）用紧凑模型达到同等性能？
- **为什么重要**：TAD 是三维基因组的基本功能单元，边界预测是理解染色质结构-功能关系的基础步骤。现有深度学习方法（如 deepTAD）依赖 CNN+Transformer 的大容量架构，计算成本高、可解释性差，且其性能增益是否真正来自架构容量而非数据/标注质量尚不明确。
- **现有方法为何不足**：① 大架构的参数效率低，训练和推理成本高；② 通用架构（CNN+Transformer）需要从数据中隐式学习 TAD 边界的几何特征，浪费容量；③ 缺乏对「架构容量 vs. 任务先验」的系统解耦分析。
- **精确研究问题**：Can a compact architecture with an explicit axial-contrast inductive bias achieve TAD boundary prediction performance comparable to a much larger CNN+Transformer baseline?

## 04 背景与发展脉络

> 注：以下脉络主要基于本文 Introduction 的叙述，标注为「仅本文框架」；外部核验部分单独标注。

**阶段一：经典信号处理方法（本文框架）**
- 代表方法：Directionality Index (DI) [3]、Insulation Score (IS) [8]、TopDom [9]、HiCExplorer [10,11]、OnTAD [12]
- 优点：计算轻量、可解释
- 局限：依赖手工设计的统计特征和线性扫描窗口，预测结果对参数（如窗口大小）敏感，跨研究可重复性低

**阶段二：深度学习方法（本文框架）**
- 代表方法：deepTAD [21]（CNN+Transformer）、其他基于 CNN/Transformer 的边界预测模型
- 优点：能自动学习非线性接触模式，性能优于经典方法
- 局限：架构越来越大，参数多、计算成本高；未充分利用 TAD 边界的几何先验

**阶段三：本文位置（经外部核验）**
- AxialTAD 提出「紧凑架构 + 任务对齐归纳偏置」的设计路线：将 TAD 边界定义为接触矩阵中沿行/列方向的强度突变，用显式的轴向对比算子替代通用注意力机制，在参数减少 76%–80% 的同时保持性能。
- 该思路与三维基因组领域中「利用结构先验设计专用模型」的趋势一致（如基于 TAD 层级结构的模型），但本文是首个系统验证「轴向对比」这一具体几何先验在边界预测中价值的 work。

## 06 核心思想

**1) 表面方法**：
- 输入：15×15 的 Hi-C 接触矩阵 patch（以候选 bin 为中心）
- 架构：卷积编码器（2 层 CNN + max-pooling）→ CBAM 通道注意力（去掉空间注意力）→ **Axial Contrast Module（ACM）** → 融合头（1×1 卷积）→ 中心位置分类
- ACM 核心操作：对特征图沿上/下/左/右四个方向做位移（shift），计算 signed difference 和 absolute difference，分别堆叠为垂直（行轴）和水平（列轴）对比张量，再经轴向卷积（垂直方向用 3×5 核、水平方向用 5×3 核）评估对比信号的空间连续性
- 训练：Adam 优化器，二元交叉熵损失（label smoothing 0.01），He uniform 初始化，30 epoch，基于验证 F1 选模型

**2) 核心洞察**：
- TAD 边界的几何本质是接触矩阵中沿行/列方向的强度突变（对角线块状结构的角点），这一先验可以**显式编码**为轴向对比算子，无需通用注意力机制从数据中隐式学习
- 在 15×15 的局部 patch 尺度上，边界预测任务的信息瓶颈不在模型容量，而在**任务本身的几何结构**——因此紧凑架构 + 任务对齐归纳偏置可以替代大容量通用架构
- 轴向对比的「方向性」是关键：垂直对比（行轴）和水平对比（列轴）分别捕捉边界两侧的上下/左右接触差异，二者互补

**3) 可能的普适教训 [Analysis]**：
- 在三维基因组任务中，**结构先验的显式编码**可能比盲目扩大模型容量更有效——尤其是当任务具有清晰的几何/拓扑特征时（如 TAD 边界的轴向对比、环的锚点模式、区室的块状结构）
- 「参数匹配对照」是评估归纳偏置价值的必要实验设计：仅当控制参数/FLOPs 后仍存在性能差异，才能归因于架构设计而非容量
- 参考标注（reference）的选择对 F1 绝对值影响巨大（本文中跨 reference 差异达 0.37），跨方法比较时必须统一 reference 或使用外部生物学验证（如 CTCF/cohesin）

## 07 方法总览

- **输入**：15×15 Hi-C 接触矩阵 patch（KR 归一化，逐行标准化），中心 bin 为候选边界
- **输出**：中心 bin 的边界概率（sigmoid）
- **模块**：
  1. **卷积编码器**：Conv(128, 3×3) → ReLU → MaxPool(3×3, stride 3) → Conv(64, 3×3) → ReLU，输出 5×5×64 特征图
  2. **CBAM 通道注意力**：仅用通道注意力分支（空间注意力被刻意省略，因其各向同性会干扰轴向对比编码）
  3. **Axial Contrast Module（ACM）**：
     - 对特征图 X 沿上/下/左/右四个方向做位移（shift），位移量 d ∈ {1, 2}（D=2 默认）
     - 计算 signed difference（X_shift − X）和 absolute difference（|X_shift − X|）
     - 垂直堆叠（F_v）：上/下方向的 signed + absolute 差，通道数 4DC = 512
     - 水平堆叠（F_h）：左/右方向的 signed + absolute 差，通道数 4DC = 512
     - 轴向卷积：F_v 用 3×5 核（沿行轴评估垂直对比的连续性），F_h 用 5×3 核（沿列轴评估水平对比的连续性），各输出 32 通道
  4. **融合头**：拼接 R 和 C → 1×1 卷积（32 通道，ReLU）→ 1×1 卷积（1 通道，线性）→ 中心位置提取 → sigmoid
- **训练**：Adam，二元交叉熵（label smoothing 0.01），He uniform 初始化，30 epoch，验证 F1 选优
- **后处理**：Wilcoxon 秩和检验过滤（p < 0.05），与 deepTAD 协议一致
- **流程**：候选 bin 枚举 → patch 提取 → 标准化 → 模型前向 → 中心 logit → sigmoid → Wilcoxon 过滤 → 最终边界集

## 09 关键公式符号

**1. 位移差分（ACM 第一步）**：

对特征图 X ∈ ℝ^(H×W×C)，沿方向 s ∈ {up, down, left, right}、位移 d ∈ {1, ..., D}：

- signed difference: X^(s,d) − X
- absolute difference: |X^(s,d) − X|

**2. 轴向堆叠**：

- F_v = Concat_c( X^(up,1) − X, |X^(up,1) − X|, X^(down,1) − X, |X^(down,1) − X|, ..., X^(up,D) − X, |X^(up,D) − X|, X^(down,D) − X, |X^(down,D) − X| ) ∈ ℝ^(H×W×4DC)

- F_h = Concat_c( X^(left,1) − X, |X^(left,1) − X|, X^(right,1) − X, |X^(right,1) − X|, ..., X^(left,D) − X, |X^(left,D) − X|, X^(right,D) − X, |X^(right,D) − X| ) ∈ ℝ^(H×W×4DC)

**3. 轴向卷积**：

- R = ReLU( Conv_{3×5}( F_v ) ) ∈ ℝ^(H×W×M)，M = 32
- C = ReLU( Conv_{5×3}( F_h ) ) ∈ ℝ^(H×W×M)

**4. 门控**：

- G_R = σ( Conv_{1×1}( R ) )，G_C = σ( Conv_{1×1}( C ) )
- R̃ = G_R ⊙ R，C̃ = G_C ⊙ C

**5. 融合与中心提取**：

- L = Conv_{1×1}( ReLU( Conv_{1×1}( Concat_c(R̃, C̃) ) ) ) ∈ ℝ^(H×W×1)
- s = L[⌊H/2⌋, ⌊W/2⌋, 0]
- p = σ(s)

**符号表**：
- H, W：特征图空间维度（H = W = 5）
- C：通道数（C = 64）
- D：最大位移量（D = 1 或 2）
- M：轴向卷积输出通道数（M = 32）
- σ：sigmoid 函数
- ⊙：逐元素乘法
- Concat_c：沿通道维拼接

## 10 实验设计与证据链

**数据集与规模**：
- 人类：4 个细胞系（GM12878、HeLa-S3、IMR-90、K562），染色体 1–22，25 kb 分辨率，KR 归一化
- 训练/验证/测试：染色体级别划分（chr20–22 测试，chr16/17/19 验证，其余训练），共 56 训练对、12 验证对、12 测试对
- 小鼠：mESC Micro-C 和 CH12-LX in situ Hi-C，25 kb，染色体 1–19，留一染色体交叉验证
- 参考标注：三种 reference（filtered OnTAD、unfiltered OnTAD、OnTAD ∩ HiCExplorer intersection）

**基线**：
- deepTAD（CNN+Transformer，571K 参数，原始实现）
- 参数匹配的 plain-CNN 对照（~137K 参数）

- 指标：Precision、Recall、F1（严格 bin 匹配，无位置容差）

## 11 结论正确解读

- **任务范围**：本文结论仅适用于「基于 15×15 局部 patch 的 TAD 边界二分类」这一任务设定，不适用于其他分辨率（如 5 kb、50 kb）、其他物种（除小鼠验证外）、其他三维基因组特征（如 A/B compartment、loop）的预测。
- **性能声明边界**：AxialTAD 与 deepTAD 的「可比」是在 F1 差异 ≤ 0.02 的意义上，且仅在 intersection reference 下成立；在 filtered reference 下绝对 F1 大幅下降（~0.23），但架构间可比性保持。
- **归纳偏置的边界**：轴向对比的优势仅在 10 kb 分辨率和两个小鼠数据集中显著；在 25 kb 人类数据上，参数匹配的 plain-CNN 与 AxialTAD 无显著差异。因此「轴向先验优于通用卷积」的结论是条件性的，不能泛化为普遍优势。
- **生物学验证的边界**：CTCF/cohesin 富集分析是关联性证据，不构成独立边界准确率验证。K562 中 CTCF 富集缺失但 RAD1 富集的现象提示可能存在 CTCF 非依赖的边界机制，但本文未深入探究。
- **计算成本声明**：参数减少 76%–80% 是事实，但训练/推理时间反而更长（AxialTAD 训练时间为 deepTAD 的 1.54 倍），因此「紧凑」不等于「高效」。
- **端到端状态**：本文是「patch 分类」而非「全基因组边界检测」的端到端系统；实际应用需额外的候选 bin 枚举和 Wilcoxon 后处理。
- **最终结论（有边界表述）**：在 15×15 patch 尺度的 TAD 边界分类任务中，显式编码轴向对比的紧凑架构（113K–137K 参数）可以达到 571K 参数 CNN+Transformer 基线的 F1 水平，并在部分条件下（10 kb、小鼠数据）优于参数匹配的通用卷积对照；但该优势并非在所有条件下成立，且未转化为计算效率优势。

## 14 学到什么

> 以下为 Agent 提炼的知识候选，面向「三维基因组/染色质组织 × AI/物理模拟」课题方向。

1. **任务先验的显式编码可以替代架构容量**：TAD 边界的几何本质（轴向接触强度突变）可以被显式编码为差分算子，无需大容量通用架构隐式学习。这一思路可迁移到其他三维基因组任务——例如 loop 检测（锚点的成对接触模式）、compartment 识别（块状结构的边界）、以及 Hi-C 数据增强（接触矩阵的局部几何约束）。

2. **「参数匹配对照」是评估归纳偏置价值的金标准**：本文通过构造参数匹配的 plain-CNN 和 pointwise 对照，将「架构设计」与「模型容量」两个变量解耦。这一实验设计可直接迁移到三维基因组领域的任何架构比较研究——仅当控制参数/FLOPs 后仍存在性能差异，才能归因于架构先验。

3. **分辨率是归纳偏置有效性的调节变量**：轴向对比在 10 kb 分辨率下优于通用卷积，但在 25 kb 下无差异。这提示：分辨率越低（信息越稀疏），任务先验的价值越大。在三维基因组建模中，选择归纳偏置时应考虑目标分辨率——高分辨率任务可能需要更强的结构先验。

4. **参考标注的选择主导 F1 绝对值**：本文中 filtered/unfiltered/intersection 三种 reference 导致 F1 从 0.23 到 0.60 的差异，远大于任何架构间差异。这警示：三维基因组领域的基准测试必须统一 reference 或使用外部生物学验证，否则跨研究比较无意义。

5. **生物学验证需要多标记交叉验证**：本文发现 K562 中 CTCF 富集缺失但 RAD21 富集，提示单一标记可能不足以验证边界预测。在三维基因组研究中，应使用多个独立标记（CTCF、cohesin、H3K4me3、housekeeping gene 启动子等）交叉验证预测结果。

6. **紧凑模型的「紧凑」不等于「高效」**：AxialTAD 参数少但训练/推理时间更长，说明参数计数不是计算效率的充分指标。在三维基因组大规模应用中，应同时报告参数、FLOPs、实际运行时间和内存占用。

7. **差分算子是捕捉接触矩阵局部变化的有效工具**：ACM 的 signed/absolute difference 设计可视为一种可学习的梯度算子，与物理模拟中常用的有限差分方法有概念上的联系。这一思路可迁移到基于物理的染色质模型——用可微的差分算子替代手工设计的能量项。

## 15 与已有知识连接

- **deepTAD [21]**：本文的直接基线和方法论来源。deepTAD 建立了「patch 分类 + CNN + Transformer」的框架，AxialTAD 保留该框架但替换核心模块。可对比阅读以理解「通用架构 vs. 任务先验」的差异。
- **DI [3] / IS [8]**：经典 TAD 边界检测方法。本文明确指出 ACM 编码的信号与 DI/IS 手工统计量在几何上一致（轴向接触差异），但以可学习方式实现。这连接了经典方法与深度学习方法。
- **OnTAD [12] / HiCExplorer [10]**：本文 reference 标注的来源。OnTAD 的层级 TAD 调用和 HiCExplorer 的 insulation 方法代表了当前 TAD 标注的主流工具，其局限性（参数敏感、标注偏差）是本文讨论的一部分。
- **CBAM [25]**：本文使用通道注意力模块，但刻意省略空间注意力。CBAM 原文展示了通道/空间注意力的互补性，本文的省略决策为「任务对齐的注意力设计」提供了案例。
- **CTCF/cohesin 与 TAD 边界 [28]**：本文的生物学验证基于 CTCF 和 RAD21 与 TAD 边界的已知共定位关系。这一连接将计算预测与三维基因组的功能机制联系起来。
- **4D Nucleome (4DN) [22]**：数据来源。4DN 提供了标准化的 Hi-C 数据处理流程，本文的 KR 归一化、染色体划分等协议可追溯至 4DN 标准。
- **ENCODE [29]**：ChIP-seq 数据来源。ENCODE 的标准化 peak calling 和 signal track 为本文的生物学验证提供了可靠输入。
- **候选方向（未在本文中验证）**：本文的轴向对比思想与 Hi-C 的「边界处接触频率突变」这一物理特征直接相关，可连接到基于聚合酶动态或环挤压模型的 TAD 边界形成机制研究。

## 16 研究想法

> 以下为 Agent 生成的研究候选，每个均标注创新状态。

**候选 1：轴向对比先验的跨任务迁移——loop 检测**
- **名称**：AxialLoop：基于轴向对比的染色质环锚点检测
- **来源局限/观察**：本文证明轴向对比对 TAD 边界有效；loop 锚点在接触矩阵中同样具有方向性对比特征（锚点处接触频率的局部峰值），但几何模式不同（点状 vs 线状）
- **核心假设**：轴向对比算子可泛化到 loop 锚点检测，但需要修改差分方向（对角 vs 轴向）
- **初步方法**：在 ACM 基础上增加对角差分分支，在 HiCCUPS 标注的 loop 数据集上训练
- **验证方式**：与 HiCCUPS、peakachu 等基线比较 F1 和参数效率
- **创新状态**：unverified

**候选 2：分辨率自适应的轴向对比**
- **名称**：Multi-resolution axial contrast for TAD boundary prediction
- **来源局限/观察**：本文发现轴向对比的优势在 10 kb 显著、25 kb 不显著，提示分辨率是关键调节变量
- **核心假设**：多分辨率特征融合可让轴向对比在更宽的分辨率范围内保持优势
- **初步方法**：在编码器中引入多尺度位移（d ∈ {1,2,4}）并自适应加权
- **验证方式**：在 5/10/25/50 kb 四个分辨率下系统比较
- **创新状态**：unverified

**候选 3：轴向对比与物理模拟的融合**
- **名称**：Physics-informed axial contrast：将环挤压模型约束注入 TAD 边界预测
- **来源局限/观察**：TAD 边界的轴向对比特征源于环挤压因子（cohesin）在边界处的停滞，这一物理机制可建模为约束
- **核心假设**：将环挤压模型的物理约束（如 cohesin 停留时间、CTCF 方向性）作为正则项，可提升边界预测的生物学有效性
- **初步方法**：在损失函数中加入基于环挤压模拟的物理正则项，或在 ACM 中引入 CTCF 方向性特征
- **验证方式**：与本文 CTCF/cohesin 富集分析对比，检验预测边界的生物学支持率
- **创新状态**：unverified

**候选 4：轴向对比的可解释性分析**
- **名称**：Interpreting axial contrast：归因分析揭示 TAD 边界的几何特征
- **来源局限/观察**：本文作者承认未进行归因分析（Discussion 第 2 段）
- **核心假设**：归因分析可揭示 ACM 是否真正编码了「轴向对比」而非其他混杂特征
- **初步方法**：使用 Grad-CAM 或 Integrated Gradients 对 ACM 的预测进行归因，分析显著区域是否集中在 TAD 边界对角线
- **验证方式**：与 DI/IS 手工特征图对比，检验归因图与几何先验的一致性
- **创新状态**：unverified

**候选 5：轴向对比在单细胞 Hi-C 的迁移**
- **名称**：Axial contrast for single-cell Hi-C TAD boundary detection
- **来源局限/观察**：本文仅使用 bulk Hi-C；单细胞 Hi-C 数据稀疏、噪声大，可能需要更强的几何先验
- **核心假设**：轴向对比的显式先验在稀疏数据下比通用架构更鲁棒
- **初步方法**：在 scHi-C 数据上微调 AxialTAD，或在 ACM 中引入稀疏性正则
- **验证方式**：与现有 scHi-C 结构检测方法比较，评估在低覆盖度下的性能保持
- **创新状态**：unverified

**候选 6：轴向对比的通用性——A/B compartment 边界**
- **名称**：Extending axial contrast to compartment boundary detection
- **来源局限/观察**：A/B compartment 边界在接触矩阵中表现为块状结构的转变，与 TAD 边界的线状对比不同
- **核心假设**：轴向对比可扩展为「块状对比」算子，用于 compartment 边界检测
- **初步方法**：将 ACM 的位移差分改为块级池化差分，在 compartment 标注上训练
- **验证方式**：与基于 PCA 的 compartment 调用方法比较
- **创新状态**：unverified
