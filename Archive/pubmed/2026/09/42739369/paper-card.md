## 03 研究问题

- **具体问题**：深度学习模型如何利用 DNA 序列、染色质状态和三维基因组组织信息来解析植物的 cis-regulatory code？不同架构（CNN、Transformer、GNN）在这些任务上的适用性和局限是什么？
- **为什么重要**：大量与农艺性状相关的位点位于非编码区，理解 cis-regulatory code 对分子育种和基因工程至关重要。植物基因组具有多倍性、转座子密度高、缺乏 CTCF 直系同源物等独特特征，不能直接套用动物模型的方法论。
- **现有方法为何不足**：(1) PWM 假设基序位置独立，无法捕捉基序内依赖和高阶组合；(2) k-mer 依赖词长和稀疏性，缺乏长程上下文；(3) 多数模型在作者自定义测试集上评估，缺乏独立验证和实验确认；(4) 单参考基因组训练无法充分代表结构变异和替代单倍型。
- **精确的「Can ... ?」研究问题**：Can deep learning models trained on plant DNA sequence and multi-omics data reliably predict cis-regulatory function beyond author-defined test sets, and can their predictions be distinguished from mere statistical association?

## 06 核心思想

**1) 表面方法**：本文是一篇综述，系统比较了 CNN、Transformer/基因组语言模型、GNN 三类架构在植物 cis-regulatory code 解析中的应用，涵盖转录因子结合预测、染色质可及性预测、基因表达建模、变异效应预测和调控序列设计五个任务领域。

**2) 核心洞察**：本文的核心主张是「三维轴框架」——植物 cis-regulatory code 由三个相互作用的轴构成：线性序列（编码潜在调控信息）、染色质状态（决定可及性和表观标记）、三维基因组组织（将远端元件带到启动子附近）。深度学习模型可以建模这些轴的组件，但**模型输出的统计依赖关系不能等同于物理接触或因果功能**。作者反复强调：预测性能、物理接触和生物学功能是三个不同层次的主张，需要不同强度的证据支持。

**3) 可能的普适教训 [Analysis]**：本文对「预测-因果」边界的强调具有超越植物学的普适性。在三维基因组/染色质组织建模中，一个模型可能在序列特征上取得高 AUC，但这既不证明它学到了真实的染色质折叠机制，也不证明预测的远程互作具有功能意义。本文提出的「证据强度匹配主张强度」原则——计算预测 → 报告活性 → 内源编辑 → 表型测量——可以作为该领域验证范式的参考模板。此外，作者对「数据泄漏」和「评估者身份」的区分（开发者评估 vs 独立评估）也值得三维基因组建模社区采纳。

## 07 方法总览

> 本文为综述，无单一方法流程。以下按文中框架整理各建模范式的输入-输出-模块结构。

- **输入**：DNA 序列（one-hot、k-mer、BPE token）、表观基因组信号（ATAC-seq、ChIP-seq、甲基化）、3D 接触数据（Hi-C、Hi-ChIP）
- **输出**：转录因子结合位点、染色质可及性、基因表达水平、变异效应分数、设计序列
- **模块**：
  - 编码器：CNN（局部 motif 提取）、Transformer/状态空间模型（长程依赖）、GNN（图结构上的消息传递）
  - 任务头：分类头（结合/不结合）、回归头（表达水平）、生成头（序列设计）
- **训练**：预训练 + 微调范式（如 AgroNT 的 masked language modeling、PlantCAD 的 Mamba 架构）
- **推理**：零样本评分或微调后预测
- **文字流程**：DNA 序列 → 编码（one-hot/k-mer/BPE）→ 架构前向传播（CNN/Transformer/GNN）→ 任务头输出 → 后处理（如变异效应 = 参考 vs 替代等位基因的预测差异）→ 实验验证（报告基因、CRISPR 编辑）

## 09 关键公式符号

> 本文为综述，无新公式。以下为文中涉及的建模概念的形式化描述 [Analysis]。

**1) 变异效应分数（Variant effect score）**

$$\Delta S = f(x_{alt}) - f(x_{ref})$$

- $x_{ref}$：参考等位基因的编码序列
- $x_{alt}$：替代等位基因的编码序列
- $f(\cdot)$：训练好的模型预测函数
- $\Delta S$：预测的调控效应差异

**用途**：优先候选调控变异。注意：$\Delta S$ 反映模型敏感性，不直接等于生物学效应强度。

**2) 序列编码（one-hot）**

$$\mathbf{X} \in \{0,1\}^{4 \times L}, \quad \sum_{i=1}^{4} X_{i,j} = 1 \ \forall j$$

- $L$：序列长度
- 4 行对应 A、C、G、T

**3) 接触矩阵归一化（文中提及 Knight–Ruiz / ICE）**

$$\hat{C} = \text{KR}(C) \quad \text{或} \quad \hat{C} = \text{ICE}(C)$$

- $C$：原始接触计数矩阵
- $\hat{C}$：归一化后的接触矩阵

**用途**：消除测序深度、距离衰减等技术偏差。

## 11 结论正确解读

- **任务范围**：本文覆盖植物 cis-regulatory code 的五个任务——TF 结合预测、染色质可及性预测、基因表达建模、变异效应优先排序、调控序列设计。不涉及蛋白编码变异效应、剪接调控等。
- **真值/标签来源**：训练标签来自 ChIP-seq、ATAC-seq、RNA-seq 等实验测定；这些标签本身受抗体质量、组织异质性、测序深度等影响。
- **端到端状态**：多数模型是「序列 → 分子表型」的端到端预测，但**没有**模型实现「序列 → 农艺性状」的端到端预测。
- **算力成本**：文中未提供各模型的训练成本比较。
- **历史依赖**：模型依赖训练数据的物种、基因型、组织和条件覆盖；跨物种迁移效果因任务而异。
- **最难情形**：多倍体基因组、转座子密集区域、结构变异效应、非参考序列的调控功能预测。
- **群体/领域边界**：结论主要适用于训练数据覆盖的物种和条件；植物中缺乏 CTCF 直系同源物意味着动物衍生的 3D 基因组规则不能直接迁移。
- **有边界的复述**：深度学习模型在植物 cis-regulatory 任务上展现了预测能力，但当前证据主要来自作者自定义测试集；预测性能、物理接触和因果功能是三个不同层次的主张，需要匹配强度的验证——计算预测需要独立评估，调控功能需要报告基因或内源编辑证据，农艺效应需要表型测量。

## 14 学到什么

> **Agent 提炼的知识候选**

1. **「预测-接触-功能」三层区分框架**：本文最核心的可迁移概念。在三维基因组建模中，一个模型可能预测了远程互作（统计依赖），但这不等于物理接触（需要 Hi-C/3C 验证），更不等于调控功能（需要报告基因或编辑验证）。三维基因组课题应明确每个 claim 属于哪一层，并匹配相应强度的证据。

2. **评估轴的五维分解**：内部划分（随机/染色体/基因家族）、外部数据集、独立团队、实验验证、跨物种迁移——这五个维度应分别报告，而非笼统说「验证」。三维基因组建模社区可采纳此框架。

3. **数据泄漏的相似性感知划分**：重叠窗口、同源序列、同源异型基因、共享样本都可能导致虚假的高性能。三维基因组数据中，同源序列（paralogs）和重复区域尤其容易造成泄漏。

4. **植物 3D 基因组的特殊性**：缺乏 CTCF 直系同源物意味着动物衍生的 TAD/loop 规则不能直接迁移。三维基因组建模需要植物特异的基准测试和特征工程。

5. **多模态融合的条件匹配问题**：当整合序列+表观+3D 接触时，需要确保训练/测试数据的条件匹配（同一组织、同一发育阶段、同一环境），否则模型可能学到批次效应而非生物学信号。

6. **生成式设计的验证标准**：生成序列需要报告基因验证，且应报告活性、特异性、非预期活性和可重复性。三维基因组课题中，如果生成「调控序列」，应明确验证平台（报告基因 vs 内源编辑）和验证尺度。

7. **pangenome-aware 表示的必要性**：单参考基因组无法代表物种的调控多样性。三维基因组建模应考虑图表示或 haplotype-aware 表示，特别是在多倍体作物中。

## 15 与已有知识连接

- **Enformer（非植物）**：本文引用为长上下文序列模型的代表。Enformer 的 196,608 bp 输入窗口和注意力机制是植物长程调控建模的参考架构。连接点：植物中是否有类似规模的模型？本文指出植物中缺乏系统验证。
- **DNABERT-2**：BPE tokenization 的非植物先例。连接点：BPE 边界是否对应生物学 motif 是开放问题。
- **Nucleotide Transformer**：多物种预训练的非植物先例。连接点：植物物种覆盖度如何影响下游任务迁移。
- **DeepSEA / Basenji 系列**：多任务 CNN 预测染色质特征的经典框架。PlantDeepSEA 是其植物版本。连接点：多任务学习是否在植物中同样有效。
- **AlphaFold 的「预测 ≠ 机制」教训**：AlphaFold 预测结构但不揭示折叠机制。类似地，调控模型预测活性但不揭示调控机制。连接点：三维基因组建模应避免过度解读。
- **GWAS 的「关联 ≠ 因果」原则**：与本文「预测 ≠ 因果」一脉相承。连接点：变异效应预测分数应视为优先排序工具而非因果证据。
- **候选方向 [Analysis]**：本文未深入讨论扩散模型在调控序列设计中的应用，也未讨论多组学整合（如 3D 基因组 + 单细胞多组学）的建模框架。这些可能是三维基因组 × AI 课题的下一步方向。

## 16 研究想法

> **Agent 生成的研究候选**

**候选 1：植物 3D 基因组感知的增强子-启动子预测模型**
- **名称**：Plant3D-EPI
- **来源局限/观察**：本文指出植物中缺乏直接验证的 GNN 应用，且 3D 基因组数据有限
- **核心假设**：将 Hi-C 接触矩阵作为图边信息，可提升植物增强子-启动子预测的精度和跨物种迁移能力
- **增量**：相对于 GenomicLinks 的配对序列方法，显式引入接触图结构
- **初步方法**：图神经网络 + 序列编码，节点=基因组 bin，边=归一化接触；训练目标=增强子-启动子互作二分类
- **验证方式**：染色体划分 + 跨物种（玉米→高粱）评估；报告基因验证 top 预测
- **创新状态**：unverified

**候选 2：pangenome-aware 的调控变异效应预测**
- **名称**：PanReg-VEP
- **来源局限/观察**：本文强调单参考基因组无法代表调控多样性，pangenome 表示是未来方向
- **核心假设**：基于 pangenome 图的序列表示可捕获非参考插入和结构变异对调控功能的影响
- **增量**：相对于 PlantDeepSEA 的单参考序列输入，引入图表示
- **初步方法**：pangenome 图 + 图神经网络或图 Transformer；训练目标=染色质可及性/基因表达
- **验证方式**：在含结构变异的基因型中评估预测精度；与单参考模型对比
- **创新状态**：unverified

**候选 3：预测-接触-功能三层验证框架的标准化基准**
- **名称**：PlantCis-Bench
- **来源局限/观察**：本文反复强调预测 ≠ 因果，但缺乏统一基准来区分不同层次的 claim
- **核心假设**：一个标准化的三层验证基准可以减少领域内的过度解读
- **增量**：提供统一的评估协议，区分统计预测、物理接触和功能验证
- **初步方法**：收集已有多组学数据（ATAC、Hi-C、STARR-seq、CRISPR 编辑），构建三层基准
- **验证方式**：多个模型在同一基准上比较，报告各层性能
- **创新状态**：unverified

**候选 4：植物 3D 基因组中 TE 介导的远程调控建模**
- **名称**：TE-Loop
- **来源局限/观察**：本文讨论了 TE 的调控潜力，但未深入 3D 层面；TE 可能通过改变染色质结构影响远程调控
- **核心假设**：TE 插入可通过改变 3D 基因组结构来影响邻近基因表达，且这种效应可被深度学习捕获
- **增量**：将 TE 注释与 Hi-C 数据联合建模
- **初步方法**：序列模型 + TE 注释特征 + 接触图；训练目标=TE 邻近基因表达
- **验证方式**：在玉米等 TE 丰富基因组中评估；CRISPR 删除 TE 后验证表达变化
- **创新状态**：unverified

**候选 5：不确定性量化的调控序列设计**
- **名称**：UncertDesign
- **来源局限/观察**：本文未讨论模型不确定性，但设计任务中不确定性直接关系到实验验证成功率
- **核心假设**：显式建模预测不确定性可提高设计序列的实验验证成功率
- **增量**：在生成式设计中引入不确定性估计（如 ensemble 或 Bayesian 方法）
- **初步方法**：训练 ensemble 模型，设计时同时优化预测活性和低不确定性
- **验证方式**：报告基因实验验证设计序列，比较有/无不确定性约束的成功率
- **创新状态**：unverified
