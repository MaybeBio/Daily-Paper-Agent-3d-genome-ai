## 02 一句话总结

本文提出 ssJSD 框架，将 scHiC 接触矩阵按基因组距离带状聚合为概率向量，并显式整合结构零（SZ）稀疏性信息，通过早期融合（拼接）或晚期融合（多种均值）计算 Jensen-Shannon 散度作为细胞间不相似性，在模拟与真实数据上证明其聚类性能优于仅用接触频率的 JSD 方法。

## 03 研究问题

- **具体问题**：scHiC 接触矩阵中超过 90% 的条目为零，但并非所有零等价——部分代表真实生物学上无互作（结构零，SZ），部分源于技术性丢失（dropout，DO）。现有不相似性度量（如 JSD、HiCRep）将所有零一视同仁，未利用 SZ 信息，导致聚类精度受限。
- **为什么重要**：准确识别细胞亚群是理解三维基因组异质性与细胞功能的基础；SZ 携带谱系/细胞类型特异的生物学信息，忽略它将丢失关键信号。
- **现有方法不足**：szKendall 虽利用 SZ 信息且性能优异，但计算复杂度为 O(K²L²)（K 为细胞数，L 为位点对数），难以扩展至大规模数据；平滑/嵌入类方法（SCL、GenomeDISCO、scHiCluster、Higashi）不区分零的类型。
- **精确研究问题**：能否设计一种计算高效（O(KL + K²B)，B ≪ L）的度量，在保留空间距离带状结构的同时显式整合 SZ 信息，从而在稀疏 scHiC 数据上实现优于现有方法的细胞聚类？

## 06 核心思想

1. **表面方法**：将每个细胞的 HiC 接触矩阵按基因组距离带状聚合为两个概率向量——PCF（接触频率）与 PSZ（结构零频率），然后通过早期融合（拼接为一个 2B 维向量）或晚期融合（分别计算 JSD 后以 GM/HM/AM/WM 合并）得到细胞间不相似性矩阵，最后用 PAM 或 K-means 聚类。

2. **核心洞察**：结构零不是「无信息」的缺失，而是携带生物学约束的「有信息」信号——特定基因组位点对在特定细胞类型中因拓扑结构或表观约束而从不互作。将这种「生物学缺席」显式编码为特征，等价于为每个细胞增加了一个独立的、与接触频率互补的视图。带状聚合则同时解决了稀疏性和计算复杂度两个问题。

3. **可能的普适教训** [Analysis]：在高度稀疏的高维生物数据中，「零」的语义分化（真实零 vs 技术零）往往是未被利用的信息金矿。任何处理稀疏计数矩阵的方法（如单细胞 RNA-seq、ATAC-seq）都可借鉴「将零类型作为独立特征通道」的思路，而非仅做插补或二值化。此外，「早期融合 vs 晚期融合」的对比提示：当两个数据视图的噪声结构不同时，晚期融合（分别度量后合并）可能比早期融合（拼接后统一度量）更稳健。

## 07 方法总览

- **输入**：K 个细胞的 scHiC 接触矩阵（每个为 C 条染色体的 2D 矩阵，bin 大小为 1 Mb）；每个细胞的 SZ 指示矩阵（可由 HiCImpute 等工具推断）
- **输出**：K×K 细胞间不相似性矩阵；聚类标签
- **模块**：
  1. **带状聚合**：对每条染色体，按距主对角线的距离 s=1,…,B 聚合接触频率与 SZ 计数，得到 PCF(k) 与 PSZ(k)（长度 B 的向量）
  2. **归一化**：PCF 与 PSZ 各归一化使其和等于 1/2（早期融合）或 1（晚期融合）
  3. **不相似性计算**：早期融合——拼接为 2B 维向量后计算 JSD；晚期融合——分别计算 JSD 后以 GM/HM/AM/WM 合并
  4. **聚类**：PAM（直接作用于不相似性矩阵）或 K-means（作用于 2D 投影：UMAP/t-SNE/MDS）
- **训练**：无监督，无训练过程；SZ 推断依赖外部工具（HiCImpute）
- **工具**：R 包（GitHub 提供）
- **流程**：原始接触矩阵 → 带状聚合 → 概率向量 → JSD 不相似性 → 聚类 → 评估（ARI/WSS/ASW/MIS）

## 09 关键公式符号

**1. 带状聚合（接触频率）**：
P_CF^(k)(s) = Σ_c Σ_{i=1}^{B_c - s} Y_{i, i+s, k}^{(c)}
- P_CF^(k)(s)：细胞 k 在距离带 s 上的总接触频率
- Y_{i,j,k}^{(c)}：细胞 k 中染色体 c 上位点 i 与 j 的观测接触数
- B_c：染色体 c 的 bin 数；s = 1, …, B，B = max_c B_c - 1

**2. SZ 指示聚合**：
P_SZ^(k)(s) = Σ_c Σ_{i=1}^{B_c - s} Z_{i, i+s, k}^{(c)}
- Z_{i,j,k}^{(c)} ∈ {0,1}：位点对 (i,j) 在细胞 k 中是否为结构零

**3. 早期融合归一化**：
P_C^(k)(s) = P_CF^(k)(s) / (2 Σ_{s'=1}^B P_CF^(k)(s'))，对 s ≤ B
P_C^(k)(s) = P_SZ^(k)(s-B) / (2 Σ_{s'=1}^B P_SZ^(k)(s'))，对 s > B

**4. JSD（两分布 P, Q）**：
JSD(P‖Q) = ½ D_KL(P‖M) + ½ D_KL(Q‖M)，M = (P+Q)/2
- 用于早期融合（P = P_C^(k), Q = P_C^(k')）与晚期融合（分别对 P_CF 和 P_SZ 计算）

**5. 晚期融合合并**：
- GM: D = √(D^CF · D^SZ)
- HM: D = 2 / (1/D^CF + 1/D^SZ)
- AM: D = (D^CF + D^SZ)/2
- WM: D = (w₁D^CF + w₂D^SZ) / (w₁ + w₂)，其中 w₁ = 匹配正计数对数，w₂ = 匹配 SZ 对数

**6. 模拟数据生成（接触期望）**：
log λ_ij = α₀ + α₁ log d_ij + β_l log(x_l,i x_l,j) + β_g log(x_g,i x_g,j) + β_m log(x_m,i x_m,j)
- λ_ij：位点对 (i,j) 的期望接触数；d_ij：3D 欧氏距离
- x_l, x_g, x_m：片段长度、GC 含量、可作图性协变量

## 11 结论正确解读

- **任务范围**：仅针对 scHiC 数据的细胞聚类（无监督），不涉及结构预测、3D 建模或增强子-启动子互作推断。
- **Oracle/真值输入**：模拟中 SZ 真值已知；真实数据中 SZ 由 HiCImpute 推断（概率阈值取正观测位点 SZ 概率的 95 分位数），非实验验证的 ground truth。
- **端到端状态**：方法依赖外部 SZ 推断工具（HiCImpute），非端到端；SZ 推断质量直接影响性能。
- **算力成本**：带状聚合将维度从 O(L) 降至 O(B)，复杂度 O(KL + K²B)，远低于 szKendall 的 O(K²L²)；但 HiCImpute 本身计算开销大（作者在 Discussion 中承认）。
- **历史数据依赖**：方法本身不依赖历史数据，但 SZ 推断工具的训练/校准可能隐含特定数据分布假设。
- **模型依赖**：性能上限受限于 SZ 推断准确性；作者通过鲁棒性分析（42 种误设组合）刻画了这种依赖。
- **最难情形**：低测序深度 + 高 SZ 误设率时，ssJSD 优势缩小但仍不低于基线。
- **不确定性**：真实数据中 SZ 标签无实验验证；5 细胞系结果未与最新深度学习方法（如 Higashi）直接对比；前额叶皮层结果未报告与 szKendall 的定量比较。
- **边界化复述**：在模拟与两个真实数据集上，当 SZ 推断质量合理（sensitivity/specificity ≥ 0.7）时，ssJSD 的聚类性能一致优于忽略 SZ 的 JSD 基线；但性能增益的上界受限于 SZ 推断工具的准确性，且未证明优于所有现有方法。

## 14 学到什么

> Agent 提炼的知识候选

1. **「零的语义分化」是可迁移的核心概念**：在 scHiC（以及 scRNA-seq、scATAC-seq 等稀疏单细胞数据）中，将零区分为「生物学真实零」与「技术丢失」并分别建模，可显著提升下游任务性能。迁移到三维基因组结构预测：可考虑将「结构零概率」作为辅助任务或输入特征，帮助模型区分「未观测」与「确实不互作」。

2. **带状聚合是处理超高维稀疏矩阵的高效降维策略**：将 2D 接触矩阵按基因组距离带聚合为 1D 谱向量，既保留空间距离衰减这一核心生物学规律，又将维度从 O(L) 降至 O(B)。此思路可迁移到任何基于 HiC 矩阵的深度学习模型输入设计——用距离带谱替代原始矩阵可大幅降低计算量。

3. **早期融合 vs 晚期融合的权衡**：当两个特征通道（接触频率 vs SZ 模式）的噪声结构不同时，晚期融合（分别度量后合并）比早期融合（拼接后统一度量）更稳健，尤其在 SZ 推断有误时。这提示多模态三维基因组数据整合（如 HiC + CTCF + 表观）时，应优先考虑「各模态独立度量后融合」而非「特征拼接」。

4. **鲁棒性分析的设计范式**：作者系统评估了 SZ 推断 sensitivity/specificity 的 42 种组合对性能的影响，明确了方法的「性能边界条件」。这种「对上游误差的敏感性分析」值得在依赖预测/推断模块的三维基因组方法中推广。

5. **计算复杂度是方法落地的关键考量**：szKendall 性能虽优但 O(K²L²) 不可扩展；ssJSD 通过带状聚合实现 O(KL + K²B)，使 SZ 信息利用变得可扩展。在三维基因组 × AI 方向，设计「信息丰富且计算高效」的表示是方法被广泛采用的关键。

## 15 与已有知识连接

- **HiCRep [11] 与 JSD [12]**：本文直接继承其带状聚合框架，是该方法在单细胞场景下的扩展。可对比阅读以理解从 bulk HiC 到 scHiC 的适配挑战。
- **szKendall [23]**：本文的直接前身与对照，首次将 SZ 信息用于 scHiC 不相似性度量，但计算复杂度过高。ssJSD 是其高效替代。
- **HiCImpute [21] / scHiCSRS [22]**：SZ/DO 概率建模的代表方法，本文依赖其输出作为 SZ 来源。可迁移思路：将概率输出直接作为特征（而非阈值化）可能进一步提升性能。
- **scHiCluster [13] / Higashi [20]**：基于图/深度学习的 scHiC 嵌入方法，本文未与其直接对比，但可作为「是否 SZ 信息也能提升深度嵌入方法」的后续研究方向。
- **4D Nucleome 数据门户**：5 细胞系数据来源，是 scHiC 方法评估的标准基准之一。
- **与课题方向（3D-Genome-AI）的连接**：本文不涉及结构预测，但其「结构零作为生物学先验」的思想可迁移至结构预测模型的损失函数设计（如对已知不互作位点对施加约束）或作为多模态输入特征。此外，距离带谱表示可作为轻量级输入特征用于基于 Transformer 的 3D 基因组模型。

## 16 研究想法

> Agent 生成的研究候选

**候选 1：结构零感知的 3D 基因组结构预测损失函数**
- **来源局限/观察**：本文证明 SZ 携带细胞类型特异的生物学信息，但结构预测模型（如基于 HiC 的 3D 结构重建）通常对所有零位点对一视同仁。
- **核心假设**：在结构预测模型的训练损失中，对 SZ 位点对施加更强的「不接触」约束（如增大距离惩罚权重），可提升预测结构的细胞类型特异性与生物学准确性。
- **初步方法**：使用 HiCImpute 或类似工具推断 SZ 概率，将其作为损失函数中位点对权重的先验；在模拟与真实 HiC 数据上对比加权与未加权模型的 3D 结构重建精度。
- **验证方式**：使用 FISH 验证的 3D 距离作为 ground truth，比较加权模型的预测距离误差。
- **创新状态**：unverified

**候选 2：多模态距离带谱融合的 scHiC 表示学习**
- **来源局限/观察**：ssJSD 的晚期融合优于早期融合，提示不同模态（接触频率 vs SZ 模式）应独立编码后再融合。
- **核心假设**：将接触频率谱与 SZ 谱分别编码为嵌入向量，再通过注意力机制动态融合，可学习到比固定加权（如 WM）更优的细胞表示。
- **初步方法**：设计双通道编码器（接触谱 + SZ 谱），融合层使用门控注意力；在 5 细胞系与前额叶皮层数据上评估聚类 ARI。
- **验证方式**：与 ssJSD 各变体、Higashi、BandNorm 对比；消融实验验证注意力融合的贡献。
- **创新状态**：unverified

**候选 3：SZ 概率的端到端可微估计器**
- **来源局限/观察**：ssJSD 依赖外部工具（HiCImpute）的 SZ 推断，且作者承认该环节是计算瓶颈；阈值化可能丢失概率信息。
- **核心假设**：将 SZ 概率估计作为神经网络的一个可微分支，与聚类目标联合优化，可同时提升 SZ 推断质量和聚类性能，并消除对 HiCImpute 的依赖。
- **初步方法**：设计多任务学习框架——共享编码器 + 两个头（SZ 概率预测头 + 聚类头）；损失函数为 SZ 预测（可基于模拟数据监督）与聚类（无监督）的加权和。
- **验证方式**：在模拟数据上比较端到端模型与「HiCImpute + ssJSD」管线的 SZ 推断准确率与聚类 ARI；在真实数据上评估计算时间。
- **创新状态**：unverified

**候选 4：距离带数 B 的自适应选择策略**
- **来源局限/观察**：作者未系统研究带数 B 的选择，但 B 决定分辨率与噪声的平衡，且不同数据集最优 B 可能不同。
- **核心假设**：基于数据自身特性（如接触衰减率、稀疏度）自适应选择 B，可稳定提升聚类性能。
- **初步方法**：定义 B 的选择准则（如最小化带内方差、最大化带间分离度）；在模拟与真实数据上扫描 B 并验证准则的有效性。
- **验证方式**：比较自适应 B 与固定 B 的聚类 ARI 分布。
- **创新状态**：unverified
