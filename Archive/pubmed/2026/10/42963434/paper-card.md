## 02 一句话总结

本文用 GC 组成保持的 CpG 编辑作为探针，在 Enformer 和 Borzoi 两个 oracle 上证明：预测效应的大小随测量位点（host locus）变化远超采样噪声，方向在单一 locus 上不可靠，且该异质性无法由 18 种宿主属性解释，也不能预测 lentiMPRA 实验活性。

## 03 研究问题

- **具体问题**：序列-功能模型（Enformer/Borzoi）作为 oracle 对调控元件打出的分数，其效应大小和方向是否在跨宿主位点（host locus）时保持稳定？
- **为什么重要**：这类模型被广泛用于设计调控元件、预测变异效应、打分候选增强子。若效应方向依赖宿主背景，则任何"在某一位点验证过的序列效应"都不能外推到其他位点，直接威胁基于 oracle 的元件设计流程。
- **现有方法为何不足**：此前评估多聚焦于单一位点内的相对排序或总体相关性，未系统分离"序列效应"与"宿主背景效应"；且未控制 GC 组成这一强混淆因素。
- **精确研究问题**：Can the direction and magnitude of an oracle-predicted sequence effect (a CpG edit) be transferred across host genomic loci, when sequence composition is preserved?

## 06 核心思想

**1) 表面方法**：用 GC 组成保持的 CpG 编辑作为干预探针，在 Enformer 和 Borzoi 上对多发性硬化风险区域的 24 个宿主位点进行系统打分，比较全窗口分数与局部化分数，并用 lentiMPRA 验证。

**2) 核心洞察**：oracle 预测的"序列效应"并非序列本身的固有属性，而是序列×宿主背景的交互产物。效应方向在单一 locus 上不可靠，且这种不可靠性不是聚合伪影（局部化分数下仍存在），但幅度被聚合方式放大（25 倍→3 倍）。

**3) 可能的普适教训 [Analysis]**：任何基于序列-功能模型的预测，若未显式建模宿主背景，其效应量级和方向都不可外推。对三维基因组建模而言，这意味着"序列特征→染色质结构"的映射必须包含位点特异性上下文（如拓扑结构域位置、CTCF 边界距离、复制时序等），否则预测的结构效应同样不可迁移。

## 07 方法总览

- **输入**：多发性硬化风险区域的宿主位点序列（24 个 loci，扩展至 200 个 loci 验证）；插入序列（来自 peak-derived 与 inaccessible 区域）；CpG 编辑（GC 组成保持）
- **输出**：Enformer/Borzoi 预测分数（全窗口与局部化两种聚合方式）；lentiMPRA 实验活性
- **模块**：

  3. 宿主位点选择：24 个 MS 风险区域 locus
  4. 打分：Enformer 与 Borzoi，全窗口 vs 局部化（仅插入 bin）
  5. 验证：lentiMPRA
- **训练**：不适用（使用预训练模型）
- **工具**：Enformer, Borzoi, lentiMPRA
- **假设**：GC 匹配后，序列组成差异被控制，剩余效应差异可归因于宿主背景
- **流程**：设计插入序列 → 在 24 个宿主位点放置 → 施加 CpG 编辑 → 模型打分（两种聚合） → 统计检验（宿主身份效应） → 与 18 种宿主属性关联 → lentiMPRA 验证

## 11 结论正确解读

- **任务范围**：仅限 Enformer 和 Borzoi 两个模型、CpG 编辑一种干预类型、MS 风险区域宿主位点。
- **Oracle/真值输入**：模型为预训练权重，无微调；lentiMPRA 为唯一实验验证。
- **端到端状态**：非端到端——模型预测与实验验证分离，且实验仅覆盖部分序列。
- **算力成本**：未提供。
- **历史数据依赖**：模型训练数据未讨论；MS 风险区域选择可能引入特定染色质状态偏差。
- **模型依赖**：结论限于两个 transformer 架构；其他架构（如线性模型、CNN）未测试。
- **最难情形**：单 locus 方向预测（最不可靠）；跨模型幅度一致性（Borzoi 不足）。
- **群体/领域边界**：人类基因组、MS 相关位点；未覆盖其他物种或疾病。
- **不确定性**：宿主属性（18 种）均无法预测效应，说明存在未识别的背景因素；lentiMPRA 阴性结果可能受实验系统限制。
- **有边界复述**：在 Enformer/Borzoi 上，对 MS 风险区域宿主位点施加 GC 保持的 CpG 编辑，预测效应的大小随宿主位点变化且不可由已知属性解释，方向在单一 locus 上不可靠；该结论不能外推到其他模型、编辑类型或基因组区域。

## 14 Agent 提炼的知识候选

**可迁移概念**：
1. **组成保持干预设计**：在评估序列效应时，控制 GC 组成（或更一般的 k-mer 组成）是分离"序列效应"与"背景效应"的必要条件。可迁移到三维基因组建模：预测结构效应时，需控制序列组成以避免混淆。
2. **全窗口 vs 局部化分数**：oracle 打分的聚合方式可显著改变结论（25 倍→3 倍）。三维基因组预测中，结构特征的聚合窗口（如 TAD 边界 vs 内部）同样可能改变预测结论。
3. **宿主背景交互**：序列效应不是固有属性，而是序列×背景的交互。三维基因组中，同一 CTCF motif 在不同 TAD 边界位置的绝缘效应可能不同——本文提供了系统检验此类交互的框架。
4. **模型间异质性幅度差异**：Enformer 和 Borzoi 复现异质性但幅度不同，提示模型架构影响效应量级估计。三维基因组模型选择时需考虑此不确定性。

**可迁移方法**：
- 宿主位点面板设计（24→200 loci 扩展）用于估计背景效应的稳健性检验
- 置换检验思路（宿主标签打乱）用于区分真实背景效应与随机波动
- 实验验证（lentiMPRA）作为 oracle 生态效度的必要检查

**对本课题的启示**：若用 Enformer/Borzoi 预测染色质结构相关特征（如 CTCF 结合、增强子-启动子互作），必须报告跨位点稳健性；单一 locus 的预测方向不可作为设计依据。

## 15 与已有知识连接

- **Avsec et al. (2021) Enformer**：本文审计的 oracle 之一。Enformer 的 100kb 上下文使其能捕捉远距离调控，但本文证明其预测的效应方向在跨位点时不稳健。
- **Calviello et al. (2023) Borzoi**：另一被审计 oracle。Borzoi 以 RNA 表达为训练目标，本文显示其复现异质性但幅度不足，提示训练目标影响效应量级。
- **Agarwal & Shendure (2020) 饱和诱变 + MPRA**：本文的 lentiMPRA 验证延续了"模型预测→实验验证"的范式，但结果为阴性，提示模型-实验对齐问题。
- **Karollus et al. (2023) 物种感知序列生成**：本文的六阶 Markov 链与 transformer 对比，呼应了"生成模型真实性评估"的讨论。
- **三维基因组方向**：本文的"宿主背景调制序列效应"与 TAD 边界处 CTCF motif 的方向依赖性（de Wit et al. 2015）在概念上一致——序列功能依赖上下文。可迁移：三维基因组预测模型需显式建模位点特异性上下文。

## 16 Agent 生成的研究候选

**候选 1：三维基因组 oracle 的跨位点稳健性审计**
- **名称**：Hi-C oracle transferability benchmark
- **来源局限/观察**：本文证明序列-功能 oracle 的效应方向跨位点不可靠；三维基因组预测模型（如基于序列预测 TAD/loop）可能面临同样问题
- **核心假设**：基于序列的 3D 基因组预测模型，其预测的结构特征（TAD 边界、loop 强度）在跨位点迁移时同样不稳定
- **初步方法**：选取已知 loop/TAD 边界位点，施加组成保持的序列编辑（如 CTCF motif 突变），在多个宿主位点检验预测变化的方向一致性
- **验证方式**：与 Hi-C 实验数据对比；置换检验
- **创新状态**：unverified

**候选 2：宿主背景特征的可解释性分析**
- **名称**：Host context feature attribution for sequence effects
- **来源局限/观察**：18 种宿主属性均无法预测效应方向，说明存在未识别的背景特征
- **核心假设**：存在可预测效应方向的宿主特征（如染色质状态组合、拓扑结构域位置、复制时序），但需更高维特征或非线性模型
- **初步方法**：对 24（或 200）个宿主位点提取多组学特征（ATAC、ChIP-seq、Hi-C 局部特征），训练预测效应方向的模型，用 SHAP 归因
- **验证方式**：留一 locus 交叉验证；新位点前瞻性预测
- **创新状态**：unverified

**候选 3：组成保持干预的通用框架**
- **名称**：Composition-preserving perturbation toolkit for regulatory genomics
- **来源局限/观察**：本文的 GC 匹配 CpG 编辑是控制组成混淆的有效手段，但仅覆盖一种编辑类型
- **核心假设**：将组成保持扩展到 k-mer 水平（而非仅 GC），可更彻底地分离序列效应与背景效应
- **初步方法**：开发 k-mer 匹配的编辑算法（如保持 5-mer 分布的 motif 突变），在 Enformer/Borzoi 及 3D 基因组模型上系统测试
- **验证方式**：与现有 GC 匹配方法对比；模拟数据检验
- **创新状态**：partially checked（GC 匹配已验证，k-mer 扩展未验证）

**候选 4：模型-实验对齐的校准框架**
- **名称**：Oracle calibration against MPRA for 3D genome features
- **来源局限/观察**：oracle 分数不能预测 lentiMPRA 活性，提示模型优化目标与实验读出不对齐
- **核心假设**：通过校准（如 isotonic regression 或温度缩放）可部分恢复 oracle 对实验活性的预测能力
- **初步方法**：在 lentiMPRA 数据上训练校准器，评估校准前后跨位点效应方向一致性
- **验证方式**：独立 MPRA 数据集；与未校准模型对比
- **创新状态**：unverified
