## 03 研究问题

- **具体问题**：基因组深度学习模型在预测多种基因组模态（如染色质可及性、转录因子结合、剪接等）上已达到最先进水平，但如何从训练好的模型中提取生物学上可解释的顺式调控逻辑（cis-regulatory logic）？
- **为什么重要**：模型的预测性能本身不是终点；生物学发现依赖于理解模型学到了什么模式（如 motif、组合语法、距离关系）。缺乏易用、高效、可扩展的解释工具会严重限制深度学习在基因组学中的科学产出。
- **现有方法为何不足**：现有解释工具往往针对特定模型架构或特定任务定制，缺乏通用性；计算效率低，难以处理全基因组尺度的 in silico 饱和突变；缺乏统一的 API 和内存管理，难以集成到现有工作流中。
- **精确研究问题**：Can a single, highly optimized, model-agnostic toolkit provide scalable and interpretable analyses (e.g., in silico mutagenesis, attribution, motif discovery) for any genomic deep learning model, thereby enabling biological discovery from predictive performance?

## 06 核心思想

1. **表面方法**：构建一个 Python 工具包，提供统一的 API 用于对任意基因组深度学习模型进行解释分析，包括 in silico mutagenesis、feature attribution、motif discovery 等，并针对 GPU 和内存效率进行高度优化。

2. **核心洞察**：基因组深度学习模型的科学价值不在于模型本身，而在于如何「打开」模型。通过将「模型」与「解释」彻底解耦（everything-but-the-model），可以构建一套通用的、可扩展的分析流程，使研究者无需修改模型代码即可获得生物学见解。

3. **可能的普适教训** [Analysis]：在三维基因组/染色质组织领域，深度学习模型（如预测 Hi-C、CTCF loop、enhancer-promoter interaction）同样面临「预测好但解释难」的问题。tangermeme 的「模型无关解释层」思路可迁移：任何训练好的染色质组织模型都可以用统一的归因/突变工具来解析其学到的序列特征（如 CTCF motif 方向性、cohesin loading motif、拓扑关联域边界序列偏好），从而将预测性能转化为对染色质组织机制的假设。

## 07 方法总览

- **输入**：训练好的基因组深度学习模型（任意架构，如 CNN、ResNet、Transformer）+ 基因组序列（FASTA 或 one-hot encoding）
- **输出**：多种解释结果，包括：
  - in silico mutagenesis 分数（每个位置每个碱基替换对预测的影响）
  - feature attribution 图（如 saliency、DeepLIFT 风格分数）
  - motif 发现结果（从归因分数中提取的序列模式）
- **模块**：
  - 序列处理模块（one-hot 编码、批处理、内存池）
  - 模型封装模块（统一模型接口，支持任意 PyTorch 模型）
  - 解释模块（ISM、attribution、motif discovery）
  - 可视化模块（归因图、motif logo）
- **训练**：不涉及模型训练；工具包仅用于已训练模型的解释
- **工具**：Python、PyTorch、GPU（CUDA）
- **反馈回路**：解释结果 → 生物学假设 → 新实验 → 新模型 → 再解释
- **假设**：模型已充分训练且预测性能良好；模型学到的模式与真实生物学机制相关

**文字流程**：
1. 用户提供训练好的模型和感兴趣的基因组区域序列
2. tangermeme 将序列编码为 one-hot 张量，按批次加载到 GPU
3. 对每个位置进行 in silico 饱和突变（逐位替换为 A/C/G/T），记录模型输出变化
4. 或计算 feature attribution 分数（通过反向传播或近似方法）
5. 从归因分数中提取显著富集的序列模式（motif）
6. 输出可视化结果（热图、logo、突变轨迹）

## 14 Agent 提炼的知识候选

**标题**：Agent 提炼的知识候选

1. **模型无关解释层架构**：将「模型」与「解释」彻底解耦，构建统一的解释 API。可迁移到三维基因组领域：任何预测 Hi-C、CTCF loop、TAD 边界的模型都可以用同一套 ISM/attribution 工具解析其序列偏好，无需为每个模型重写解释代码。

2. **In silico mutagenesis 的规模化实现**：全基因组饱和突变是计算密集操作，tangermeme 的 GPU 批处理和内存管理策略可借鉴。三维基因组模型（如预测 enhancer-promoter interaction）常需扫描全基因组候选区域，高效的 ISM 实现可显著加速 motif 发现。

3. **从归因到 motif 的端到端流程**：将 attribution 分数转化为可解释的 motif 是解释工具的关键环节。三维基因组领域可借鉴此流程：从 Hi-C 预测模型的归因分数中提取染色质组织相关 motif（如 CTCF、cohesin loading motif），并检验其方向性偏好。

4. **「预测性能 ≠ 生物学发现」的方法论提醒**：该文的核心立场是模型性能只是起点，解释才是科学产出。三维基因组领域的深度学习模型（如预测 TAD 边界）同样需要从「预测准确」走向「机制理解」，tangermeme 的定位为此提供了方法论示范。

## 15 与已有知识连接

- **DeepLIFT / SHAP**：tangermeme 的 attribution 模块与这些特征归因方法同源，但强调统一 API 和规模化。三维基因组领域已有工作使用 DeepLIFT 解析 CTCF loop 预测模型（如 Enformer 相关分析），tangermeme 可视为此类方法的工程化整合。
- **tfmodisco**：motif 发现工具，tangermeme 的 motif discovery 模块与之功能重叠。三维基因组领域可结合两者：用 tangermeme 生成归因分数，再用 tfmodisco 提取 motif。
- **Enformer / Basenji**：基因组深度学习模型的代表，tangermeme 可用于解释这类模型学到的调控逻辑。三维基因组领域常使用 Enformer 的 embedding 或预测头进行染色质组织分析，tangermeme 可为此类分析提供解释工具。
- **候选方向 [Analysis]**：三维基因组领域的「everything-but-the-model」工具尚不成熟，tangermeme 的架构可作为模板，开发面向 Hi-C/3D 模型的专用解释工具包（如支持多模态输入、loop 预测头的归因分析）。

   - **验证方式**：在已知 TAD 边界（如 mESC、K562）上验证发现的 motif 组合是否与 ChIP-seq 共结合模式一致。
